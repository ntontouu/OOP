Η εφαρμογή αποτελείται από τα αρχεία Pomodoro.hpp, Pomodoro.cpp, ergasia.cpp και το αρχείο Makefile που χρησιμοποιείται για το compile. 
Επίσης περιλαμβάνονται τα αρχεία catch.hpp και test.cpp  που χρησιμοποιούνται για τον έλεγχο ορθότητας της εφαρμογής. 
Θα πρέπει να είναι αποθηκευμένα στον ίδιο φάκελο. 

Compile γίνεται με την εντολή: make. 

Για να τρέξει η εφαρμογή δίνεται σε command line: ./sessions. 

Για τρέξουν οι έλεγχοι ορθότητας θα πρέπει να δοθεί σε command line: ./test
