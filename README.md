## 📚 Ύλη & Θεωρία
Το μάθημα καλύπτει τις εξής βασικές έννοιες της C++:
* Επίπεδα προστασίας, κατασκευαστές (constructors, destructors, copy constructors).
* Υπερφόρτωση τελεστών, δείκτες, δυναμική δέσμευση μνήμης, αναδρομή.
* Κληρονομικότητα, πολυμορφισμός και ιδεατές συναρτήσεις (virtual functions).
* Πρότυπα (Templates), Εξαιρέσεις (Exceptions) και Standard Template Library (STL).
* UML - Διαγράμματα κλάσεων.
